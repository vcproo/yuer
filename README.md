# 小芽 · 养育花销模拟游戏

本轮从发现怀孕（约孕8周）开始，模拟到约6岁公办小学入学。35个回合，按年龄生成真实生活需求对应的消费任务。没有性格、能力、亲密度或收入系统。

## 运行

在本目录运行 `npm start`，打开 http://127.0.0.1:4173 。
微信开发者工具导入本目录，入口为 miniprogram/pages/life/index。项目中的 touristappid 是占位值，真机预览与发布需替换为自己的 AppID，选择较新基础库。

## 怎样玩

1. 查看本期清单，优先处理喂养、照护或入园方式等安排。
2. 必需事项必须有安排；条件任务只在相应情境出现；可选消费可逐项不买，也可统一跳过。
3. 选择消费方案，可修改单价和数量，然后确认记账。所有价格仅为可编辑的游戏初值，不是市场均价。
4. 必需品已有合用品时可以零支出处理；免费项目也是有效安排。可选消费不购买没有惩罚。
5. 本期所有任务处理后进入下一期。推进时间不收取隐藏月费。
6. 完成小学入学清单后通关，查看分类、阶段账本与CSV。

## 按阶段安排

| 阶段 | 必需或条件任务举例 | 可选任务举例 |
|---|---|---|
| 孕期 | 产检自付、待产消耗品、安全睡眠空间、婴儿基础衣物；自驾时配安全座椅 | 纪念册、婴儿房装饰、推车 |
| 0—5个月 | 分娩住院自付、喂养安排、按需奶粉与瓶具、尿裤或尿布、清洁、衣物、儿保安排 | 吸奶器、付费照护、玩具、纪念照 |
| 6—11个月 | 奶类、辅食食材、进食基础用品、活动空间安全、按需托育 | 专用辅食机、玩具 |
| 1岁 | 家庭餐食、奶类、清洁、尿裤、合脚鞋、按需照看 | 绘本、玩具、早教体验 |
| 2岁 | 如厕/尿裤安排、衣物、餐食、照看 | 兴趣体验、生日消费 |
| 幼儿园 | 入园安排、条件保教费、园内伙食、家庭餐食、按园所要求的用品与健康检查 | 兴趣课、玩具图书 |
| 小学入学 | 公办入学安排、书包、基础文具、免费教科书、按学校情况的服装 | 专用书桌、平板、纪念照 |

### 费用口径

- 奶粉仅在婴儿期选择混合或配方奶喂养后出现；1岁后不强制购买幼儿配方奶。
- 奶粉罐数、尿裤包数仅是预算初值，可修改，不是推荐喂养量或医学标准。
- 已有合用的重复使用尿布可以零采购处理，洗涤开销在清洁预算中。
- 耐用品如瓶具、吸奶器、辅食机、入园用品完成准备后不按月重收。
- 本期自选托育/照护才会生成服务账单，家人照看不虚构雇用费。
- 每学期示例覆盖6个月，幼儿园收费按5个在园月预填，可修改。家庭餐食与园内伙食分开计，未入园不收园所费用。
- 按当前示例政策，公办园学前一年保教费为零；民办填当地减免后的自付额；伙食等另列。公办小学学杂费与统一免费教材为零。
- 只统计已确认的家庭实际新增支出，不把已有物品的历史成本、免费项目或跳过消费算成花销。
- 预算只是对比，不是银行卡余额；超支不阻止继续。账单按分累计，防止金额四舍五入误差。
- 没有统一自动扣除的生活费、性格效果或高价能力加成。

## 存档与文件

当前存档键 little-sprout-care-game-v4，独立于旧版人生模拟存档，不覆盖旧账单。旧的互动宝宝演示仍留在 baby-demo.html。

- miniprogram/core/life.js：共享阶段、任务生成、条件依赖、记账、存档。
- miniprogram/core/life-scene.js：阶段插画；婴儿复用原2D角色。
- life-app.js / index.html / life.css：网页游戏。
- miniprogram/pages/life：原生微信小程序实现。
- SOURCES.md：需求分类与费用政策的公开依据。

## 验证与边界

`npm test` 覆盖必需任务阻止推进、可选跳过、奶粉与托育条件、耐用品不重复购买、6月龄辅食边界、学前保教费减免、数量金额校验、完整通关、存档与CSV。浏览器实际走通孕期到出生，验证自定义价格入账和条件任务展开。

价格不是各城市真实报价；没有通胀、医保复杂结算、家庭收入或疾病模拟。医疗任务是费用记录点，不是检查或接种日程。入学默认约6岁，具体截止日期与地区政策未建模。孕期按4周回合近似推进。微信开发者工具和iOS/Android真机仍待验收。
